# Prompt Engineering

Write prompts as production briefs.

## Prompt structure
- Task: generate, edit, retouch, replace background, create detail crop, etc.
- Subject: exact object and identifying features.
- Preserve: geometry, construction, material, color and details.
- Camera: viewpoint, framing, perspective and focal-length character when useful.
- Composition: placement, crop, negative space and orientation.
- Lighting: source size, direction, softness, fill and shadow behavior.
- Environment: background and contextual elements.
- Materials: specific surface response and texture.
- Finish: realistic commercial photography, color treatment and detail level.
- Output: aspect ratio and intended use.

## Rules
- Prefer precise nouns and observable properties.
- Avoid contradictory instructions.
- Avoid meaningless quality-word repetition.
- State the most important constraints early.
- Use a negative prompt only for relevant risks.
- For editing, clearly distinguish unchanged regions/objects from editable regions.
