# Reference Analysis

Analyze each reference independently and assign it a role.

## Reference roles
- Product identity / geometry.
- Camera angle / crop.
- Lighting.
- Background / setting.
- Material / texture.
- Color grading / art direction.
- Composition / layout.

## Method
1. Describe the visual characteristics that are actually visible.
2. Identify which properties are transferable.
3. Identify conflicts between references.
4. Keep product identity anchored to the original product photo.
5. Convert findings into concise generation/edit instructions.

Never copy incidental details from a reference unless requested. Do not use a style reference as evidence of the source product's construction.
