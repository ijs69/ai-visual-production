# Image Editing

Treat edits as controlled changes to an existing image.

## Before editing
- Identify the requested edit region.
- Identify protected regions and product details.
- Decide whether the task is local editing or a full-image transformation.
- Keep a clear list of prohibited changes.

## Editing principles
- Change only what the user requested.
- Match lighting, perspective, sharpness, grain and color temperature between edited and original regions.
- Preserve natural edges and contact shadows.
- Avoid halos, repeated textures, melted geometry, ghosting and inconsistent reflections.
- If the tool cannot guarantee local preservation, explain the limitation.

Do not describe an edit as completed until the output has actually been produced and inspected.
