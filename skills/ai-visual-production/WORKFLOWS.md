# Production Workflows

## Generate a new image
1. Confirm deliverable, intended use and output ratio.
2. Gather subject details and references.
3. Assign each reference a role.
4. Define camera, composition, lighting, background and materials.
5. Write the prompt with the most important constraints first.
6. Generate using an available image tool.
7. Inspect, correct and deliver.

## Edit an existing image
1. Analyze the source image.
2. Create a preserve/change map.
3. Identify editable and protected regions.
4. Define only the requested changes.
5. Match perspective, lighting, sharpness, grain and color temperature.
6. Execute the edit.
7. Compare source and output, especially product geometry and edges.
8. Correct defects or disclose limitations.

## Analyze visual references
1. Label each image and assign a role.
2. Describe only visible characteristics.
3. Identify transferable properties.
4. Detect conflicts between references.
5. Keep product identity anchored to the original product photo.
6. Convert findings into concise generation/edit instructions.

## Commercial product photography
1. Confirm product identity and channel (catalog, e-commerce, ad, editorial).
2. Inspect source images and protected details.
3. Choose shot type and camera viewpoint.
4. Plan background and negative space.
5. Plan key/fill/rim lighting and believable contact shadows.
6. Specify material response and texture.
7. Generate/edit with preservation constraints.
8. Check product accuracy and commercial readability.
